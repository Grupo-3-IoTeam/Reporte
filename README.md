# CONCLUSIONES

La aplicación tiene como objetivo ofrecer una solución completa para la gestión de riego en tiempo real, permitiendo a los usuarios monitorear y controlar el sistema desde cualquier dispositivo. Esta integración facilita la supervisión constante y la capacidad de respuesta inmediata, mejorando la eficiencia en el uso de agua y la salud de las parcelas.

Durante el Sprint 1, el equipo logró implementar las bases esenciales, como la landing page y funcionalidades clave para gestionar parcelas, nodos y la planificación de riego. Aunque se encontraron algunos desafíos en la integración de la planificación de riego, los avances fueron significativos, sentando las bases para una plataforma robusta.

En el Sprint 2, el equipo ha progresado aún más en la conexión y sincronización entre la API, la aplicación móvil y la aplicación embebida en Wokwi, acercándose a un sistema completamente funcional. Sin embargo, aún quedan pendientes algunos ajustes para asegurar una comunicación perfecta entre todos los componentes, consolidando así la estructura y experiencia del usuario en el sistema de riego.
